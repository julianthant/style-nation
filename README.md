# Style Nation (starter)

The starting point for a website for Style Nation, a car showroom in Mandalay, Myanmar. This repo holds only the scaffold. No Style Nation features were built here.

## Status

Not started past setup. The first commit, from September 2025, is an unmodified copy of [ixartz/Next-js-Boilerplate](https://github.com/ixartz/Next-js-Boilerplate). It has Next.js 15, Tailwind CSS 4, Drizzle ORM and Clerk authentication.

## Run the scaffold

You need Node.js 20 or later.

```bash
npm install
npm run dev
```

The boilerplate's own setup guide covers authentication, the database and deployment: https://github.com/ixartz/Next-js-Boilerplate#readme
